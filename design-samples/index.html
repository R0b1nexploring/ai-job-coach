样品对照

同一个定价页，三个方向

三个样品的产品事实、套餐内容、FAQ 完全一致，只有设计方向不同。用于对照挑选，不代表最终文案。

样品 A · 规模决策式 Buttondown 参考

单列 + 用量滑块，价格随写作量变化；差异用行式清单，无并列卡片。

样品 B · 克制三档式 Anthropic 参考

三张边框套餐列 + 月/年切换；推荐项只靠边框与一处强调标记，折叠对比表。

样品 C · 编辑出版式 Ghost 参考

角色命名套餐 + 竖线分栏（无卡片盒）；更大衬线、更多分组对比、收尾陈述。

规范依据：仓库根目录 DESIGN.md。色板沿用 apps/web/tailwind.config.js 的 ink / sage / cream / coral。
