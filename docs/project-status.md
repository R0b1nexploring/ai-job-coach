## 启动和维护

启动：

```bash
cp .env.example .env
./scripts/dev.sh
```

完整测试：

```bash
./scripts/test.sh
```

维护预览：

```bash
apps/api/.venv/bin/python scripts/maintenance.py
```

确认后执行：

```bash
apps/api/.venv/bin/python scripts/maintenance.py --execute
```
