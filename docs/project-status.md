# 项目状态

> 更新时间：2026-07-18

当前产品已收敛为单页简历优化闭环。

## 当前用户流程

```text
首页登录
→ 上传简历
→ 上传 JD 截图
→ 生成定制简历建议稿
→ 查看面试引导
→ 下载 DOCX
```

## 已完成

- [x] 首页右上角登录；
- [x] 首页直接显示简历和 JD 截图上传；
- [x] DOCX、文本型 PDF 简历解析；
- [x] PNG、JPG、WebP 文件校验；
- [x] RapidOCR 本地中文 JD 识别；
- [x] OCR 失败时的用户文字回退；
- [x] 基于原简历来源的定制简历；
- [x] Fact Guard；
- [x] DOCX 建议稿下载；
- [x] 自我介绍、重点问题、项目追问和准备清单；
- [x] 中文错误提示；
- [x] 单页组件测试和浏览器端到端流程。

## 已从当前前端移除

- 投递和投递看板；
- 岗位库与公开岗位聚合；
- 套餐、额度和订单；
- 顾问工作台；
- 管理员运营界面；
- 独立简历、面试、设置和仪表盘页面。

旧数据库表和后端兼容接口暂时保留，避免破坏已有本地数据。当前没有数据库结构变化，因此不需要新增 Alembic 迁移。

## 仍需外部条件

- 真实 LLM 的密钥、质量和成本验收；
- HTTPS、PostgreSQL、私有对象存储、备份和监控；
- 正式隐私政策、服务协议和经营主体；
- 使用真实用户授权数据进行 OCR 与建议质量验收。

所有真实验收内容必须由用户或顾问核对，不能把 AI 或 OCR 生成文字当作已验证事实。
