# 简历质量评估规则（内部工作稿）

> 版本：1.0
> 状态：未经事实核验的启发式资料，不能视为已验证的招聘事实或产品需求。
> 文末链接仅用于后续人工核验；平台观点、时间、比例和偏好尚未逐项验证。
> 用途：帮助讨论 AI 简历教练的评分规则；产品要求仅以 `PROJECT_SPEC.md` 和 `docs/product-spec.md` 为准。

## 一、HR筛选简历的核心流程

### 1.1 两阶段筛选机制

中国HR筛选简历遵循"两阶段"模式：

- **第一阶段（5秒粗筛）**：快速扫描教育背景、工作/实习经历、语言能力等关键词，判断是否进入下一轮。
- **第二阶段（30-60秒细筛）**：将简历内容与岗位需求逐项匹配，评估候选人契合度。

**关键启示**：简历必须在5秒内通过关键词"门槛"，否则直接被排除。

### 1.2 HR关注的优先级

HR在细筛阶段关注的信息优先级：

1. **教育背景**（学校、专业、学历）——硬性门槛
2. **工作/实习经历**（公司知名度、岗位相关性、业绩数据）——核心评估项
3. **技能证书**（与岗位直接相关的硬技能）——匹配度验证
4. **项目经验**（具体案例、成果量化）——能力佐证
5. **自我评价**（针对岗位的能力总结）——辅助判断

### 1.3 12项淘汰标准（来源：51job HR分享）

HR会因以下原因直接淘汰简历：

1. 简历内容混乱，排版不专业
2. 年龄/资历与岗位不匹配
3. 工作经历存在无法解释的空档期
4. 频繁跳槽（平均2-3年换一次）
5. 职业路径显示不稳定性
6. 缺乏行业相关知识
7. 职业规划不清晰
8. 缺少岗位要求的证书
9. 家庭因素可能影响工作稳定性
10. 期望薪资与预算严重不匹配
11. 价值观与企业文化冲突
12. 工作地点偏好与岗位不符

## 二、简历结构与格式规范

### 2.1 标准模块及推荐顺序

根据候选人类型，模块顺序有所不同：

**应届生/经验较少者：**
1. 个人信息
2. 求职意向
3. 教育背景
4. 实习/工作经历
5. 项目经验
6. 技能证书
7. 荣誉奖项
8. 自我评价

**有工作经验者：**
1. 个人信息
2. 求职意向
3. 工作经历（按时间倒序）
4. 项目经验
5. 教育背景
6. 技能证书
7. 自我评价

### 2.2 格式硬性要求

| 项目 | 标准 |
|------|------|
| 纸张 | A4 |
| 页数 | 严格控制在1页（经验极丰富者最多2页） |
| 布局 | **单栏布局**（双栏/多栏会导致ATS解析失败） |
| 字体 | 统一使用一种字体，字号10-12pt |
| 对齐 | 正文左对齐，日期右对齐 |
| 行间距 | 1.15-1.5倍 |
| 页边距 | 上下左右均匀，不小于1.5cm |
| 文件格式 | PDF（首选）或 DOCX（部分旧系统兼容更好） |
| 文件名 | "姓名-应聘岗位-学校/公司"格式，如"张三-产品经理-北京大学.docx" |

### 2.3 排版雷区（必须避免）

- 双栏/多栏布局（ATS解析失败的首要原因）
- 使用表格、文本框（导致内容解析错乱）
- 图片型PDF（扫描件，ATS无法提取文字，直接零分）
- 使用Canva等工具生成的图形化简历（解析兼容性差）
- 手写字体、艺术字体
- 使用下划线（应使用分隔线或加粗）
- 花哨的符号和装饰
- 水印
- 居中对齐的长段文字
- 超过3行的bullet point

### 2.4 标准section标题（ATS友好）

必须使用ATS能识别的标准标题，不可使用创意标题：

| 正确标题 | 错误示例 |
|----------|----------|
| 工作经历 | "我的旅程"、"职业足迹" |
| 教育背景 | "学习经历"、"校园时光" |
| 项目经验 | "做过的事"、"项目集锦" |
| 技能证书 | "我的技能"、"工具箱" |
| 自我评价 | "关于我"、"个人简介" |

## 三、个人信息规范

### 3.1 必填项

- **姓名**：真实姓名，不使用昵称
- **手机号码**：11位手机号，格式 138-XXXX-XXXX
- **电子邮箱**：使用专业邮箱（163、Gmail、Outlook），**绝对避免QQ邮箱**（被视为不专业）
- **现居城市**（可选但推荐）

### 3.2 中国特有字段

与西方简历不同，中国简历通常包含以下信息（根据岗位类型选择性填写）：

| 字段 | 适用场景 | 说明 |
|------|----------|------|
| 性别 | 通用 | 国企/事业单位必填，互联网企业可选 |
| 出生年月/年龄 | 通用 | 国企/事业单位必填，互联网企业可选 |
| 政治面貌 | 国企/事业单位/公务员 | 中共党员是加分项 |
| 籍贯/户籍 | 国企/事业单位 | 部分岗位有地域偏好 |
| 婚姻状况 | 部分国企 | 一般可不填 |
| 民族 | 部分国企/事业单位 | 一般可不填 |
| 身高/体重 | 特殊岗位（如空乘、销售） | 一般岗位不需要 |

### 3.3 照片规范

中国简历**建议放照片**（与西方简历不同），但有严格要求：

- **尺寸**：1寸或2寸（3:4或4:3比例）
- **底色**：白色或浅蓝色（最安全）
- **着装**：正装，得体大方
- **表情**：自然微笑，不要过度修饰
- **光线**：均匀柔和，不要有阴影
- **禁止**：自拍照、生活照、过度美颜照、非正式场合照片

### 3.4 求职意向（必填）

这是中国简历的特色模块，必须清晰明确：

- **目标岗位**：具体岗位名称（如"产品经理"而非"管理类岗位"）
- **期望城市**：1-2个目标城市
- **到岗时间**：如"随时"、"一个月内"
- **期望薪资**：可选填，如填写建议写范围（如"15K-20K"）

## 四、核心内容撰写标准

### 4.1 STAR法则（中国版）

中国HR广泛认可的简历撰写方法论：

- **S（Situation）情境**：简述工作背景
- **T（Task）任务**：明确你的职责范围
- **A（Action）行动**：你具体做了什么（使用强动词）
- **R（Result）结果**：量化的成果（这是"王牌"）

### 4.2 动词升级指南

**弱动词（避免使用）：**
- "负责..."（过于被动）
- "参与..."（角色不明确）
- "协助..."（贡献不清晰）

**强动词（推荐使用）：**

| 场景 | 推荐动词 |
|------|----------|
| 领导力 | 主导、牵头、统筹、带领、规划 |
| 执行 | 搭建、开发、实现、完成、落地 |
| 优化 | 优化、重构、改进、升级、迭代 |
| 协作 | 协调、推动、对接、联动、协同 |
| 成果 | 达成、超额完成、突破、创造、实现 |
| 分析 | 分析、诊断、评估、调研、洞察 |
| 创意 | 策划、设计、构思、提出、创新 |
| 管理 | 管理、运营、维护、监控、保障 |

### 4.3 量化成果的四维度

中国HR认可的量化方式：

1. **数量维度**：用户数、粉丝数、客户数、订单量
   - 示例："粉丝从0增长至10万"
2. **效率维度**：时间缩短、流程优化、转化率提升
   - 示例："转化率提升15%"
3. **质量维度**：准确率、满意度、好评率
   - 示例："客户满意度从85%提升至96%"
4. **成本维度**：节省费用、降低损耗、提高ROI
   - 示例："年度运营成本降低30万元"

### 4.4 Before/After 对照示例

| 修改前（弱） | 修改后（强） |
|-------------|-------------|
| 负责公司公众号运营 | 主导公司公众号内容策略，3个月内粉丝从0增长至1.2万（+40%），单篇最高阅读量5万+ |
| 参与产品开发 | 独立搭建用户增长模块，实现日活提升25%，贡献全产品30%新增用户 |
| 负责客户服务 | 优化客户服务流程，将平均响应时间从4小时缩短至45分钟，客户满意度提升至96% |
| 管理社群 | 统筹运营5个核心用户社群（总计2万人），月均活跃度从15%提升至45%，带动复购率提升12% |

### 4.5 自我评价撰写标准

**必须避免的写法：**
- "性格开朗、工作认真负责、吃苦耐劳"（空洞无物）
- "热爱学习、善于沟通、团队协作能力强"（毫无区分度）
- 大段抒情文字

**正确写法原则：**
- 针对目标岗位，用事实佐证能力
- 列出4-10条与岗位直接相关的核心能力
- 每条能力用数据或案例支撑
- 突出"匹配度"而非"我很优秀"

**优秀示例：**
```
- 5年互联网产品经验，主导过3个从0到1的产品，累计用户超500万
- 精通数据分析，熟练使用SQL/Python，曾通过数据洞察推动产品改版，DAU提升35%
- 具备跨部门协调能力，曾统筹技术、设计、运营三方团队完成季度OKR
- 持有PMP证书，熟悉敏捷开发流程
```

## 五、ATS系统适配指南（中国市场）

### 5.1 中国主流ATS系统

| 系统 | 市场份额/特点 | 典型客户 |
|------|--------------|----------|
| 北森（Beisen） | 市占率第一（21.3%），全流程AI覆盖 | 蒙牛、京东、泸州老窖，70%中国500强 |
| Moka | 专注科技公司，AI语义匹配准确率92% | 小红书、蔚来、得物 |
| 大易（Dayee） | 传统行业强势（能源、制造、基建），合规性强 | 国企、金融机构 |
| 猎聘（Liepin） | 依托人才库，聚焦中高端岗位 | 中高层管理岗 |

### 5.2 ATS五层漏斗筛选机制

1. **文档解析**：将PDF/Word转为线性文本
   - 风险：复杂布局导致解析错误或乱码
2. **信息结构化（NER）**：提取姓名、联系方式、教育、技能等字段
   - 风险：非标准标题导致数据被跳过
3. **硬性条件过滤**：学历、工作年限、证书等硬性门槛
   - 不满足则直接淘汰，不进入评分
4. **多维度评分**：
   - 关键词匹配度（权重40-50%）
   - 经历相关性（权重20-25%）
   - 段落完整性（权重15-20%）
   - 解析成功率（权重10-20%）
   - 学历/证书匹配（权重10-15%）
5. **相对排名**：按总分排序，HR通常只看前10-20%

### 5.3 关键词权重分布（关键发现）

关键词在简历中的位置直接影响其权重：

| 关键词位置 | 权重倍数 | 说明 |
|-----------|---------|------|
| 最近一份工作的职位名 | 3.0x | 对当前能力水平的最高置信信号 |
| 个人总结/headline | 2.5x | 候选人定位的高权重区域 |
| 独立技能栏 | 2.0x | 结构化，便于JD直接匹配 |
| 证书栏 | 2.0x | 高置信度硬技能信号 |
| 最近工作经历的bullet points | 1.5x | 在上下文中证明应用能力 |
| 3年前的工作经历bullet points | 0.7x | 因时效性被降权 |

### 5.4 ATS优化策略

**"三重放置"法则**：确保核心JD关键词至少出现在三个高权重区域：
1. 个人总结/求职意向
2. 技能证书栏
3. 最近工作经历

**格式生存法则**：
- 使用单栏布局
- 使用标准section标题
- 提交可选中文本型PDF或DOCX
- 不使用表格、文本框、图形元素
- 联系方式不要放在页眉页脚（部分ATS会忽略）

## 六、不同类型企业的简历差异

### 6.1 互联网企业

- **重点**：数据驱动、用户增长、产品思维
- **风格**：简洁高效，突出量化成果
- **偏好**：大厂实习/工作经历是重大加分项
- **关键词**：DAU/MAU、转化率、用户增长、A/B测试、敏捷开发
- **篇幅**：严格1页
- **照片**：可选

### 6.2 国企/央企/事业单位

- **重点**：稳定性、合规意识、流程规范
- **风格**：正式严谨，使用规范用语，避免网络用语
- **偏好**：党员身份、名校学历、相关证书、学生干部经历
- **关键词**：合规、流程管理、制度建设、风险防控
- **篇幅**：1页（可附详细材料页）
- **照片**：必须放，正装证件照
- **个人信息**：政治面貌、籍贯等建议填写
- **格式**：按时间顺序（正序），强调稳定性

### 6.3 外企

- **重点**：国际化视野、跨文化沟通能力
- **风格**：接近西方简历规范
- **偏好**：海外经历、英语能力、多元文化背景
- **格式**：通常需要中英文各一份
- **照片**：通常不放（与西方一致）

## 七、中国简历 vs 西方简历关键差异

| 维度 | 中国简历 | 西方简历 |
|------|---------|---------|
| 照片 | 建议放（正装证件照） | 通常不放（避免歧视争议） |
| 个人信息 | 含性别、年龄、政治面貌等 | 仅姓名、联系方式 |
| 篇幅 | 严格1页 | 1-2页均可 |
| 自我评价 | 常见模块，需针对岗位 | 通常用Summary/Objective |
| 求职意向 | 必填模块 | 无此概念 |
| 排版风格 | "方块式"模块化排版 | 更灵活的排版 |
| 学历描述 | 强调学校层次（985/211/双一流） | 强调GPA和学位类型 |
| 动词使用 | 使用中文强动词（主导、推动） | 使用Action Verbs（Led, Drove） |
| 文件命名 | "姓名-岗位-学校" | "FirstName_LastName_Resume" |
| 邮箱选择 | 避免QQ邮箱 | 无特殊限制 |

## 八、简历加分项与减分项

### 8.1 加分项

- 985/211/双一流院校背景
- 知名大厂实习/工作经历（BAT、TMD等）
- 业绩数据描述清晰（有具体数字支撑）
- 与岗位高度相关的证书（如CPA、PMP、CFA等）
- 字迹工整（手写环节）
- 专业证件照
- 学生干部/社团领导经历（应届生）
- 竞赛获奖（与岗位相关）
- 海外经历（外企加分）
- 党员身份（国企加分）

### 8.2 减分项

- 学历不达标
- 频繁跳槽（平均2-3年换一次）
- 工作经历时间线有空档
- 业绩描述无数据支撑
- 自我评价空洞
- 排版混乱
- 使用QQ邮箱
- 文件名不规范（如"简历final最终版222"）
- 错别字、标点不统一
- 照片不专业（自拍、生活照）
- 一份简历投所有岗位（无针对性）

## 九、针对JD定制简历的方法论

### 9.1 "一岗一版"原则

核心要求：**每个岗位投递都需要一份定制简历**。通用简历投10个岗位，可能有8个因关键词不匹配而被ATS淘汰。

### 9.2 JD分析与简历对齐步骤

1. **提取JD关键词**：从岗位描述中提取核心技能、工具、证书、经验要求
2. **识别硬性门槛**：学历、工作年限、必备证书等（不满足则不建议投递）
3. **关键词三重放置**：将核心关键词放入个人总结、技能栏、最近工作经历
4. **经历重排**：按与JD的相关度重新排列工作经历和项目经验的优先级
5. **措辞对齐**：使用JD中的原始措辞（如JD写"用户运营"，简历也用"用户运营"而非"社区管理"）
6. **缺口标注**：JD要求但简历中没有的能力，标注为"能力缺口"而非编造

### 9.3 定制化检查清单

- [ ] 简历中的岗位关键词覆盖率 >= JD要求的70%
- [ ] 最近工作标题与目标岗位名称匹配
- [ ] 核心技能在技能栏中有对应条目
- [ ] 工作经历bullet points包含具体应用场景（非单纯堆砌关键词）
- [ ] 自我评价针对该岗位重写
- [ ] 文件命名包含目标岗位名称

## 十、简历质量评分维度（用于AI评估）

基于以上研究，建议AI简历教练使用以下评分维度：

### 10.1 评分权重

| 维度 | 权重 | 评估内容 |
|------|------|---------|
| 岗位匹配度 | 30% | 关键词覆盖率、经历相关性、求职意向清晰度 |
| 内容质量 | 25% | STAR法则应用、量化成果、动词强度、bullet point质量 |
| 格式规范 | 20% | 排版专业度、ATS兼容性、模块完整性、篇幅控制 |
| 个人信息 | 10% | 必填项完整性、照片规范、联系方式专业度 |
| 自我评价 | 10% | 针对性、事实支撑、与岗位匹配度 |
| 细节质量 | 5% | 无错别字、标点统一、时间线连续、文件命名规范 |

### 10.2 各维度评分细则

**岗位匹配度（30%）：**
- 满分：JD核心关键词覆盖率>=80%，经历高度相关
- 良好：覆盖率60-80%，经历较相关
- 及格：覆盖率40-60%，部分经历相关
- 不及格：覆盖率<40%，经历与岗位无关

**内容质量（25%）：**
- 满分：所有经历使用STAR法则，成果100%量化，使用强动词
- 良好：大部分经历有量化，动词较有力
- 及格：部分经历有数据，动词一般
- 不及格：无量化成果，使用"负责"等弱动词

**格式规范（20%）：**
- 满分：单栏布局、标准标题、1页、ATS友好格式
- 良好：基本规范，个别格式问题
- 及格：可读但有明显格式缺陷
- 不及格：双栏/图形化/超2页/解析风险高

## 十二、关键结论与产品应用建议

### 12.1 核心发现

1. **ATS是第一道关卡**：98.4%的世界500强使用ATS，中国以北森、Moka为主。格式不兼容=直接零分。
2. **关键词匹配决定生死**：占评分权重的40-50%，且位置比数量更重要。
3. **量化成果是核心竞争力**：中国HR特别看重数据支撑的业绩描述。
4. **一岗一版是基本要求**：通用简历的淘汰率高达80%。
5. **中国简历有独特规范**：照片、个人信息、求职意向等与西方简历有本质差异。
6. **企业类型决定风格**：互联网重数据、国企重稳定、外企重国际化。

### 12.2 产品应用方向

AI简历教练在进行简历优化时，应重点关注：

1. **ATS兼容性检查**：确保输出格式能被主流中国ATS系统正确解析
2. **JD关键词提取与匹配**：自动从JD提取关键词，评估覆盖率，建议补充
3. **STAR法则改写**：将"负责XX"自动改写为"行动+量化结果"格式
4. **动词升级**：自动将弱动词替换为强动词
5. **格式规范化**：确保单栏布局、标准标题、合理篇幅
6. **个性化建议**：根据目标企业类型（互联网/国企/外企）调整建议风格
7. **Fact Guard**：所有改写必须基于原简历已有事实，不编造数据或经历
